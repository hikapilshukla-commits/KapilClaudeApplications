# Claude Java MCP Starter

A basic implementation of chat applications and Model Context Protocol (MCP) servers using the Anthropic Java SDK.

## Description
This repository contains basic applications like a chat interface and MCP-based tools. It is designed to demonstrate how to integrate Claude APIs into Java projects using the official Anthropic Java SDK.

## Features
- **Basic Chat:** Simple interaction with Claude models.
- **MCP Server:** Tool integration based on the Model Context Protocol.
- **Java Native:** Built entirely using the Anthropic Java SDK.

## Prerequisites
- **Java 17** or higher.
- **Maven**
- An **Anthropic API Key** (set as an environment variable `ANTHROPIC_API_KEY`).

## Getting Started
1. Clone the repo:
   ```bash
   git clone https://github.com
   ```
2. Navigate to the project folder and build:
   ```bash
   mvn clean install
   ```
3. Run the application.
